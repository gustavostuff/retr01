# 02 — User interface

## Shell and rendering

| Setting | Value | Notes |
|---------|-------|-------|
| Window backend | SDL2 | Window, input, GPU texture upload |
| UI toolkit | Dear ImGui (docking branch) | Dockable panels, property editors |
| Base resolution | 960×720 or 1280×720 | Integer scale only (2×, 3×) for crisp pixel previews |
| Screen preview | 256×240 logical | Scaled with nearest-neighbor |
| Theme | Dark default | Match PPUX-style tool aesthetic; optional light later |

Application entry: `app/main.c` creates SDL window, ImGui context, dock space, and loads last project path from user config (optional JSON in `~/.config/retr01-studio/` or beside binary).

## Panels

### 1. World Grid

Evolve [`world_examples_generator/`](../world_examples_generator/) into an interactive editor.

| Feature | Behavior |
|---------|----------|
| Grid size | `grid_w`, `grid_h` per world (1–64 each) |
| Cell paint | Click empty cell → create playfield screen at `(col, row)` |
| Parallax paint | Shift+click or mode toggle → create `flags=1` cell (not enterable) |
| Neighbor preview | Highlight N/E/S/W neighbors of selected cell |
| Caps | Warn at 64 screens/world; block add beyond cap |
| Multi-world | Tab or dropdown for world 0–7 |
| Visual language | Blue = playfield, purple = parallax, dark = hole (matches visualizer) |

**Actions:** New screen, delete screen, jump to Screen Painter for selected cell, set start cell (boot position).

### 2. Screen Painter

PPUX Sketch-like canvas for the active screen.

| Mode | Input | Result |
|------|-------|--------|
| Tile paint | Left click | Place 8×8 tile from active CHR bank |
| Pixel paint | Left click (pixel mode) | Edit within tile; may split tiles on Generate |
| Eyedropper | Alt+click | Pick tile index + palette |
| Flood fill | Fill tool | Connected region by tile or color |
| Attr view | `A` toggle | Overlay 2×2 attr cell boundaries + palette IDs |

**Toolbar:** Pen, fill, line, rect, eyedropper, tile/pixel mode, zoom 1×/2×/4×, grid overlay, reference PNG import (256×240, optional).

**Generate (critical path):** Runs `pack/` dedupe — unique 8×8 tiles from canvas, Retr01 attr plane (240 bytes), updates CHR bank. Shows dialog if unique tile count > 256.

**Links:** Active BG bank index (0–3), authored bank stored in screen metadata for `load_screen`.

### 3. CHR / Pattern Bank

| Feature | Behavior |
|---------|----------|
| View | 16×16 grid of 8×8 previews per half-bank (BG 0–255, sprite 0–255) |
| Bank tabs | 4 banks per world |
| Selection | Click tile → active brush in Screen Painter |
| Import | PNG sheet or paste from another bank |
| Stats | Unique count, duplicates merged, overflow warning |

Sprite half is editable for preview stub OAM; v1 preview uses a simple 8×8 player sprite from bank 0.

### 4. Palette

| Feature | Behavior |
|---------|----------|
| Master ramp | 32–64 RGB entries (B1 TBD; default from project asset) |
| BG palettes | 4 rows × 4 colors; index 0 = shared backdrop |
| Sprite palettes | 4 rows × 4 colors; index 0 = transparent |
| Screen assignment | Per-tile via attr plane in painter |

Editor writes `master_palette` and per-world palette slots into `.r01proj`.

### 5. Screen Properties

Inspector for the active screen:

- `col`, `row`, `flags` (read-only if set by grid)
- Authored BG bank (0–3)
- Screen ID / label (for build log)
- **Parallax span group** — link adjacent parallax cells (span 1 or 2)
- Collision overlay toggle (future layer; v1 paint optional, export as parallel grid)

### 6. Parallax Setup

Dedicated sub-panel when a parallax cell is selected:

| Field | Maps to runtime |
|-------|-----------------|
| Axis | `PARALLAX_H` or `PARALLAX_V` |
| Span | 1 or 2 cells (256 or 512 px loop) |
| Drive | `PARALLAX_CAMERA` (divisor) or `PARALLAX_AUTO` (px/frame) |
| Factor | Divisor or speed value |
| Band height | `set_parallax_height(scanlines)` — visible band from top |

Validation: if parallax enabled on world, warn when world-mode camera is `CAM_BOTH` (runtime will force 1-axis). See [04_world_mode_packs.md](04_world_mode_packs.md).

### 7. World Mode Pack

| Feature | Behavior |
|---------|----------|
| Pack dropdown | `side_platformer`, `topdown_8way`, `single_screen`, `vertical_climb`, `paddle_2way` |
| Axis overrides | Movement, transition, physics, camera (within pack limits) |
| Summary line | Human-readable: e.g. "Platformer, H camera, smooth scroll" |
| Lint button | Run pack linter without full build |

Per-world override (advanced): different pack per world — v2; v1 one pack for whole project.

### 8. Live Preview

Embeds `retr01_emu` framebuffer in a dock panel.

| Feature | Behavior |
|---------|----------|
| Transport | Play / pause / step frame |
| Input | WASD or arrow keys → `$FE60` stub |
| Camera | Uses selected pack rules |
| Reload | Hot-reload CHR/MAP without full rebuild when possible (Phase 4) |
| Overlay | Optional: grid, seam margin (2 tiles), camera rect |

Does not replace full game testing; proves scroll, parallax band, and fade tables.

### 9. Build and Export

| Control | Action |
|---------|--------|
| Validate | Schema + CHR caps + MAP size estimate + pack linter |
| Export MAP/CHR only | Intermediate artifacts to `build/intermediate/` |
| Build cart | Full pipeline → `build/<name>.retr01` |
| Play in emulator | Spawn or attach `retr01_emu` with built cart |
| Open build folder | OS file manager |

Build log panel: cc65 stdout, MAP bytes, warnings (parallax + CAM_BOTH, fade + smooth on same axis).

## Menu structure

**File:** New project, Open `.r01proj`, Save, Save as, Recent, Quit

**Edit:** Undo/redo (painter, per-screen history), Copy/paste tile selection, Project settings

**View:** Panel toggles, zoom presets, attr overlay, grid overlay

**Build:** Validate, Build cart, Play in emulator, Export PNG sheet (CHR)

**Help:** Link to `planning/` docs, hardware spec README, keyboard shortcuts

## User workflows

### Workflow A — Single-room puzzle

1. New project → World 0, grid 1×1
2. Paint room in Screen Painter → Generate
3. World Mode: `single_screen`, movement 8-way, transition INSTANT
4. Build → preview movement within one screen

### Workflow B — Horizontal platformer

1. World Grid: linear 14×1, paint each screen
2. Set start cell col 0
3. Pack: `side_platformer`, CAM_H, SMOOTH
4. Optional: parallax row above playfield (`flags=1`, span 2)
5. Build → scroll east, seam fill at col+1

### Workflow C — Top-down with fade doors

1. Packed 8×8 grid, sparse screens
2. Pack: `topdown_8way`, CAM_BOTH
3. Mark door links in project (screen A edge → screen B) with transition FADE at link
4. Tool bakes fade palette tables at build time

## Error and warning UX

| Severity | Example | UI |
|----------|---------|-----|
| Error | CHR unique tiles > 256 | Modal; block Generate |
| Error | cc65 assemble fail | Build log + red status |
| Warning | Parallax + CAM_BOTH override | Yellow banner in Parallax Setup |
| Warning | MAP estimate > 1.17 MB | Build dialog confirm |
| Info | Seam has no neighbor | Gray note on World Grid edge |
