## What it is

CMOS 8-bit microprocessor, 6502 family with W65C02S extensions (70 instructions, 16 addressing modes). Fully static: PHI2 may stop high or low without losing register state. Retr01 runs it as the **only game logic CPU** -- it never paints a framebuffer; it streams MAP/VRAM, fills OAM ports, and writes `$FExx` latches.

## Retr01 role

| Item | Value |
|------|-------|
| Clock | **PHI2 = 8.000 MHz** (external oscillator; do not rely on PHI1O/PHI2O for system timing) |
| Address space | 64 KB: RAM `$0000-$7FFF`, **32 KB** PRG `$8000-$FDFF` / vectors `$FF00-$FFFF`, I/O `$FE00-$FEFF` (no PRG banking) |
| Board rules | **BE = high**, **RDY = high** (with pull-up) unless single-stepping or WAI |
| Island | **C** first: CPU + system RAM + tiny PRG |

## Memory / registers (programming model)

| Register | Width | Notes |
|----------|-------|-------|
| A | 8 | Accumulator |
| X, Y | 8 | Index |
| PC | 16 | PCH:PCL |
| S | 8 | Stack page fixed at **`$01xx`** (high byte implied `1`) |
| P | 8 | Flags: **N V 1 B D I Z C** (bit 5 always 1) |

### Interrupt / reset vectors

| Vector | Addr | Source |
|--------|------|--------|
| NMIB | `$FFFA/$FFFB` | Edge on NMIB |
| RESB | `$FFFC/$FFFD` | Reset |
| BRK/IRQB | `$FFFE/$FFFF` | BRK or IRQB |

Reset: hold RESB low >= 2 clocks after VDD good; release starts a **7-cycle** reset sequence; PC loads from `$FFFC/$FFFD`. Hardware clears D and sets I; other regs are software-init.

## Pin behavior (sim-critical)

| Pin | Dir | Function |
|-----|-----|----------|
| A0-A15 | Out (Hi-Z if BE=0) | Address |
| D0-D7 | In/Out (Hi-Z if BE=0) | Data |
| RWB | Out (Hi-Z if BE=0) | **1 = read**, **0 = write** |
| BE | In | **1 = bus drivers on** (Retr01 normal) |
| PHI2 | In | Master clock |
| PHI1O / PHI2O | Out | Legacy clocks; WDC: use external osc on PHI2 |
| RESB | In | Active-low reset |
| IRQB | In | Level IRQ (masked by I) |
| NMIB | In | Edge NMI |
| RDY | In/Out | Low stalls CPU; WAI drives low |
| SYNC | Out | High during opcode fetch cycle |
| MLB | Out | Low on RMW modify/write (ASL/DEC/INC/.../TRB/TSB) |
| VPB | Out | Low while reading interrupt vectors |
| SOB | In | Falling edge can set V (legacy; unused on Retr01) |
| NC | -- | Leave open |
| VDD / VSS | Power | 5 V / GND |

### One PHI2 cycle (read vs write)

From Fig 6-3 (general timing):

1. **Falling PHI2:** new address / RWB / control settle after `tADS`.
2. **Read:** memory must present data before falling PHI2 (`tDSR`); hold after fall (`tDHR`). Access window from stable address: `tACC`.
3. **Write:** CPU drives data after **rising** PHI2 (`tMDS`); holds past falling PHI2 (`tDHW`).
4. Measure at **50% VDD**.

### AC numbers (5.0 V +/-5% column, 14 MHz grade table -- use as upper bound; Retr01 clocks 8 MHz)

| Symbol | Meaning | 5 V column (ns) |
|--------|---------|-----------------|
| tCYC | Cycle time min | 70 |
| tADS | Address setup max | 30 |
| tAH | Address hold min | 10 |
| tACC | Access time min available | 30 |
| tDSR / tDHR | Read data setup / hold min | 10 / 10 |
| tMDS / tDHW | Write data delay max / hold min | 25 / 10 |

At **8 MHz**, tCYC = 125 ns -- SRAM and cart must meet that with decode + mux delay. Sim can start **functional** (edge-driven bus) and later enforce these delays.

## Expected I/O patterns (unit tests)

| Stimulus | Expect |
|----------|--------|
| RESB low then high, PHI2 running, BE=1, RDY=1 | After reset seq, fetch from `$FFFC/$FFFD`, then execute from vector |
| Opcode fetch | SYNC high that cycle; RWB=1; address = PC |
| `STA abs` write cycle | RWB=0; D = A; address = effective addr |
| IRQB low, I=0 | After current insn: push P/PC, set I, fetch `$FFFE/$FFFF`; VPB low on vector reads |
| RDY low before PHI2 fall | CPU holds; address stays |
| BE=0 | A, D, RWB Hi-Z |

## Communication on Retr01

```text
W65C02S
  A[15:0], D[7:0], RWB, PHI2
       |
       +---> decode PLD / HC573  ($FExx selects)
       +---> AS6C62256 system RAM  ($0000-$7FFF, CPU-only)
       +---> SST39SF040 PRG        ($8000+, gated)
       +---> VRAM path via mux     (interleaved; CPU phase only)
       +---> ATmega1284P ports     ($FE20 OAM, $FE60 pads) as I/O bytes
       +---> ATmega328P APU        ($FE40-$FE5F) as I/O bytes
```

IRQ sources (raster compare, etc.) wire to **IRQB**. Video NMI (VBlank) to **NMIB** when that island exists.

## Sim notes

- Full ISA + documented cycle counts is the Phase 1 accuracy target for this chip.
- Do not implement PHI1O/PHI2O-based timing; clock the core from PHI2 only.
- Stack always `$0100-$01FF`.
