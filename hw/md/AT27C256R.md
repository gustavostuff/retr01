# AT27C256R: Color PROM (master palette)

**Package (Retr01 motherboard):** 28-pin PDIP (600 mil).  
**Qty:** **1** (packed R3G3B2 OTP).  
**Organization:** **32K x 8** (256 Kbit). Retr01 uses **64** entries (6-bit index).

## Package dimensions

| | |
|--|--|
| Outline | PDIP-28, 600 mil |
| Body (nom.) | **36 x 14 mm** (length x width) |
| Sim @ 4 px/mm | **144 x 56 px** horizontal (default) |
| Reference | [`packages_dip.md`](packages_dip.md) |

## What it is

5 V **one-time programmable** parallel ROM. Factory-programmed as the board **Color PROM**: address = palette index, data = `{RRRGGGBB}` DAC code. During play it is **read-only** on the **video path**, not on the 6502 bus.

Replaces **AT28C16** (150 ns EEPROM). Too slow for ~186 ns/dot without extra pipeline. **AT27C256R-45** (**45 ns** `tACC`) meets dot clock with margin and is cheaper in production.

## Retr01 role

| Topic | Spec |
|-------|------|
| Master palette | **64 colors** (indices 0-63) |
| Cart | Palette **indices only** in `.retr01` |
| Active game pals | `$FE08`/`$FE09` load indices -> compositor -> PROM |
| Address pins | Drive **A5-A0** with index. **Tie unused address high/low to GND** |
| Analog out | R-2R per gun -> **75 ohm** to **GND** -> **~0.7 Vpp** RGBS ([`passive_rf_etc.md`](../../docs/passive_rf_etc.md)) |

## Speed (vs dot clock)

| Item | Value |
|------|------|
| Dot period | ~**186 ns** @ 5.369318 MHz |
| `tACC` (AT27C256R-45) | **45 ns** typ |
| Pipeline | Compositor may still use 1-dot index latch. PROM is no longer the bottleneck |

## Programming

Bench OTP programmer only (12 V algorithm per Microchip datasheet). Not field-rewritable on the game board. Studio Color PROM export should match the same **R3G3B2** packing as legacy AT28C16 notes ([`AT28C16.md`](AT28C16.md)).

## Sim / bring-up

Sim may still instantiate **AT28C16** until the chip model is renamed. Behavior is the same **64-entry** read-only table. Update refdes **U24** and timing when the netlist switches.

## Communication on Retr01

```text
Compositor palette index (6 bit) --> A[5:0] (+ CE/OE from video)
        |
   AT27C256R (64 used entries)
        |
   R-2R + 75R to GND --> RGBS
```

No W65C02S D-bus connection during play.
