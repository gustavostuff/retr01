# 24C64-class: Cart I2C EEPROM

> **In the 32-IC BOM** (on the cartridge). Vendor datasheet may vary by second-source. This note covers the Retr01 role and sim stub. Not a substitute for the chosen part's datasheet.

**Package (typical):** 8-pin DIP / SOIC.  
**Qty (current):** **1** - cart game saves ([`hardware.md`](../../docs/hardware.md)).  
**Organization:** **8K x 8** (64 Kbit) class (e.g. Microchip 24C64 / 24LC64).

## Package dimensions

| | |
|--|--|
| Outline | PDIP-8, 300 mil |
| Body (nom.) | **9 x 6 mm** (length x width) |
| Sim @ 4 px/mm | **36 x 24 px** horizontal (default) |
| Reference | [`packages_dip.md`](packages_dip.md) |

## What it is

5 V (or 2.5-5.5 V family) serial EEPROM with **I2C** interface: **SDA**, **SCL**, optional **WP**, plus VCC/GND. Byte or page write with ACK polling. Machine/cabinet config is **not** stored here. That lives in 1284 internal EEPROM (`$FE70-$FE72`).

## Retr01 role

| Topic | Spec |
|-------|------|
| Location | **Cartridge** (counts in the 32) |
| Contents | Per-game saves |
| Host | **ATmega1284P** I2C master -> cart **SDA**/`SCL` on 36-pin edge ([`cart.md`](../../docs/cart.md)) |
| CPU mailbox | `$FE22`-`$FE24` ([`memory.md`](../../docs/memory.md#cart-save-eeprom-24c64-on-cartridge)) |
| Board EEPROM | **Not this chip** - 1284 internal |

## Typical 8-pin pinout (confirm against chosen datasheet)

```text
         +-----\/-----+
    A0   | 1        8 | VCC
    A1   | 2        7 | WP
    A2   | 3        6 | SCL
   GND   | 4        5 | SDA
         +------------+
```

Address pins A0-A2 select the I2C device address. WP high inhibits writes (part-dependent).

## Expected I/O (bring-up)

| Stimulus | Expect |
|----------|--------|
| Idle bus | SDA released (pull-up high on hardware) |
| Start + device address + ACK | Slave ACKs when address matches |
| Write then readback | Same byte returned after write cycle |

## Sim notes (`app/sim/chips/i2c_eeprom.c`)

- Mounted as `24C64` / `U50` on island J (cart) beside SST39SF040.
- Phase-1: **pin shell + memory array stub** - no full I2C state machine yet.
- Do not treat the stub as protocol-correct silicon. Tighten when cart-save HAL lands in `02`.

## Communication

```text
6502 / 1284  --bit-bang or master-->  SDA/SCL  -->  24C64 on cart
Flash (SST39SF040)  -- parallel bus --  (separate. One CE context at a time for PRG/CHR/MAP)
```
