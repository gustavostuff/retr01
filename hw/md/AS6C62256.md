## What it is

Async CMOS SRAM: **32,768 x 8** (32 KB), fully static, TTL I/O, VCC **2.7-5.5 V**. Same JEDEC-style pinout as classic 62256 parts. Tri-state data bus controlled by CE# / OE# / WE#.

## Retr01 roles (three instances)

| Instance | CPU view | Bus rules |
|----------|----------|-----------|
| **System RAM** | `$0000-$7FFF` | CPU-only. Always available on PHI2 when selected |
| **VRAM** | via `$FE10-$FE12` | **Interleaved:** CPU phase write/read vs BG fetch phase |
| **Line buffer** | no CPU port | ATmega1284P writes in HBlank. Beam reads visible half (ping-pong 128 B) |

All three are the same silicon. Decode / mux / PLD wiring differ.

## Capacity / power (sim-relevant)

| Item | Value |
|------|-------|
| Density | 256 Kbit = 32 KB |
| Access | **55 ns** max (`tAA`, `tACE`) |
| Read/write cycle | **55 ns** min (`tRC`, `tWC`) |
| Write pulse | `tWP` min **45 ns** |
| Data retention | VCC down to **1.5 V** (battery backup use case. Retr01 is always-on 5 V) |

At Retr01 **8 MHz** (125 ns PHI2) and **~5.37 MHz** dot (~186 ns), 55 ns SRAM has margin if decode + mux stay under ~70 ns.

## Truth table

| Mode | CE# | OE# | WE# | DQ |
|------|-----|-----|-----|-----|
| Standby | H | X | X | Hi-Z |
| Output disable | L | H | H | Hi-Z |
| **Read** | L | L | H | DOUT |
| **Write** | L | X | L | DIN |

Notes: WE# must be **high** for reads. On write, OE# is don't-care in the table (still avoid fighting the bus: typically hold OE# high while CPU/writer drives DQ).

## Pin roles

| Symbol | Dir | Function |
|--------|-----|----------|
| A0-A14 | In | Byte address (15 bits -> 32 KB) |
| DQ0-DQ7 | In/Out | Data |
| CE# | In | Chip enable (active low) |
| OE# | In | Output enable (active low) |
| WE# | In | Write enable (active low) |
| VCC / VSS | Power | 5 V / GND on Retr01 |

## Timing (AS6C62256-55)

**Read:** `tRC` >= 55 ns. Data valid within `tAA`/`tACE` 55 ns from address/CE#. `tOE` 30 ns from OE#.

**Write:** `tWC` >= 55 ns. `tWP` >= 45 ns. Data setup `tDW` >= 25 ns before WE#/CE# end. Hold `tDH` >= 0.

Sim can start **combinational after delay** from CE#/OE#/WE#/addr edges. Tighten to these numbers later.

## Expected I/O (unit tests)

| Stimulus | Expect |
|----------|--------|
| CE#=H | DQ Hi-Z |
| CE#=L, OE#=L, WE#=H, addr=N | DQ = mem[N] after access delay |
| CE#=L, WE#=L, DIN=X, addr=N | mem[N] = X after write cycle |
| Addr change while selected for read | New data after `tAA`. Hold old `tOH` >= 10 ns |

## Communication on Retr01

```text
System RAM:  CPU A/D/RWB + decode CE#  ------------------> AS6C62256 #1
VRAM:        HC157 mux (CPU vs beam addr) + PLD CE#/OE# --> AS6C62256 #2
Line buffer: 1284 addr/data vs beam read mux -------------> AS6C62256 #3
```

One driver on DQ at a time. Island **C** = CPU + system RAM. Island **G** = VRAM interleave. Island **M/N** = line buffer.
