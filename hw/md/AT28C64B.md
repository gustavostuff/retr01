# AT28C64B -- Board EEPROM (legacy)

> **Legacy / bench only.** **Qty = 0** on the current 32-IC BOM ([`06`](../../docs/06_hardware_v1_32ic.md)). Machine config uses **ATmega1284P internal EEPROM** via `$FE70–$FE72`. Cart saves use **I2C EEPROM** ([`24C64.md`](24C64.md)). **No** `at28c64b.c` in the sim — intentional.

**PDF:** [`../AT28C64B_eeprom.pdf`](../AT28C64B_eeprom.pdf).  
**Package (Retr01-A):** 28-pin PDIP.  
**Qty:** **0** on current 32-IC BOM. Kept as reference for the legacy ~52 / `main` parallel-EEPROM path.  
**Organization:** **8K x 8** (64 Kbit).

## What it is

5 V parallel EEPROM with **page write** (1-64 bytes), DATA polling / toggle bit, optional software data protection. Accessed like SRAM for reads; writes are **self-timed** (busy for up to **10 ms** page / standard part).

## Retr01 role (v0)

**Board / cabinet non-volatile config** (not game cart data):

| CPU port | Function |
|----------|----------|
| `$FE70` / `$FE71` | Address (low/high as designed) |
| `$FE72` | Data |

Island **F**: write, power-cycle, read back. Soft game saves belong on a **cart** EEPROM in v1 thinking; this chip is machine-level.

## Capacity / speed

| Item | Value |
|------|-------|
| Size | **8192 bytes** (+ extra 64 B ID space in datasheet) |
| Read access | **150 ns** (`tACC` class) |
| Page write | up to **64 bytes**; `tWC` max **10 ms** (standard) |
| Page byte load window | **150 us** (`tBLC`) between bytes |
| Endurance | **100k** cycles |
| Retention | 10 years |
| VCC | 5 V +/- 10% |

150 ns is fine vs 8 MHz CPU if decode is modest; **write busy time** dominates software (poll I/O7).

## 28-pin PDIP pinout

```text
         +-----\/-----+
     NC  | 1       28 | VCC
    A12  | 2       27 | WE
     A7  | 3       26 | NC
     A6  | 4       25 | A8
     A5  | 5       24 | A9
     A4  | 6       23 | A11
     A3  | 7       22 | OE
     A2  | 8       21 | A10
     A1  | 9       20 | CE
     A0  |10       19 | I/O7
    I/O0 |11       18 | I/O6
    I/O1 |12       17 | I/O5
    I/O2 |13       16 | I/O4
    GND  |14       15 | I/O3
         +------------+
```

(Datasheet labels CE/OE/WE without `#`; treat as **active-low** enables.)

## Operating modes

| Mode | CE | OE | WE | I/O |
|------|----|----|----|-----|
| Read | L | L | H | DOUT |
| Write | L | H | L | DIN (starts cycle) |
| Standby | H | X | X | Hi-Z |

Write inhibit if OE low, or CE high, or WE high (see datasheet). Page write: successive bytes with **A6-A12 fixed** (same page); A0-A5 select byte in page.

## Device operation (sim-critical)

1. **Read:** like SRAM; data after access time.
2. **Byte/page write:** latch addr/data on WE/CE edges; internal program for `tWC`. During busy, reads of the byte under write return **polling** behavior (I/O7 = complement until done).
3. Optional **software data protect** sequences (enable/disable) -- implement if Retr01 firmware uses them; otherwise document as unused.

## Expected I/O (unit tests)

| Stimulus | Expect |
|----------|--------|
| Read after cold start | Last programmed data (or FF if blank) |
| `$FE7x` write path | Data retained across sim "power cycle" |
| Poll during `tWC` | I/O7 toggles / complements until ready |
| Page of 64 bytes | All programmed in one internal cycle if loaded in time |

## Communication on Retr01

```text
W65C02S --$FE70-$FE72--> HC573 / decode --> AT28C64B
```

Not on the video path. Not shared with cart flash.
