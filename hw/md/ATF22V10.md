**PDF:** [`../ATF22V10_pld.pdf`](../ATF22V10_pld.pdf) (Atmel / Microchip ATF22V10C).  
**Package (Retr01-A):** 24-pin DIP.  
**Qty (current):** **5** (decode, interleave, beam X/Y, compositor) -- [`06`](../../docs/06_hardware_v1_32ic.md).  
**Qty (legacy ~52):** **3** (+ optional overflow).  
**Planning part:** ATF22V10CQZ-20PU class (5 V).

## What it is

Industry-standard **22V10** architecture PLD: programmable AND array, fixed OR with **variable product terms**, **10 macrocells**. Each macrocell can be **combinatorial or registered**, active high/low, with OE. Global **CLK** (pin 1), async reset / sync preset terms. Flash-based, reprogrammable, pin-keepers on inputs/I/O.

## Retr01 role

| v0 PLD (typical split) | Job |
|------------------------|-----|
| DEC | Address decode: RAM / cart / `$FExx` /CE, PHI2 gating |
| TIM | Timing / clock enables / bus direction helps |
| PPU | CHR/VRAM phase enables, video-side selects |

v1 absorbs glue, HC161 beam, HC688 compare, and late-stage compositor mux into more PLDs -- same part family, more equations.

## Resources (sim / fit)

| Resource | Count / note |
|----------|----------------|
| Macrocells | **10** (each = OR + OLMC + FF option) |
| Product terms / macrocell | **8, 10, 12, 14, 16, 16, 14, 12, 10, 8** (edges skimpiest) |
| Dedicated inputs | ~12 + CLK |
| Bidirectional I/O | 10 |
| Speed (C-5 grade) | `tPD` ~**5 ns**, `tCO` ~**4 ns**, `fMAX` >100 MHz |

Dot clock ~5.37 MHz and CPU 8 MHz are easy for this silicon; **fit** (product terms, I/O count) is the real limit.

Pin 4 can be **power-down (PD)** when that feature is enabled in the fuse map.

## How it works

1. Designer writes equations (CUPL / WinCUPL / similar) -> JEDEC fuse file.
2. Each output = OR of its product terms (ANDs of true/complement inputs + feedbacks).
3. Registered mode: D FF clocks on pin-1 CLK rising edge; combinatorial mode bypasses FF.
4. Pin-keepers hold last level if undriven (do not leave critical nets floating in sim without modeling keepers or pullups).

### Expected behavior (unit / fixture)

| Setup | Expect |
|-------|--------|
| Programmed as AND of two inputs -> out | Truth table matches equation |
| Registered counter bit | Toggles on CLK when enable equation true |
| Unprogrammed / blank | Treat as undefined -- always load JEDEC in sim |

## Communication on Retr01

```text
CPU A[15:0], RWB, PHI2, RESB  -->  ATF22V10 (decode)
                                  -->  CE# to SRAM / flash / latches / MCUs
Beam / scroll / PPUCTRL         -->  ATF22V10 (timing / video)
                                  -->  HC157 selects, VRAM OE, IRQ hints
```

Exact pin equations are **board-specific** (not in this doc). Sim should load per-chip **equation tables** or JEDEC.

## Sim notes

- Model: 10 OLMC + AND-OR array driven by a fuse/equation image.
- Do not hardcode one global "PLD behavior" -- three (or five) instances differ.
- Escape hatch: +1 PLD if fit fails (v0 and v1).
