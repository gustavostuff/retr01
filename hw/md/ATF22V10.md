**Package (Retr01 motherboard):** 24-pin DIP.
**Qty (current):** **5** (decode, interleave, beam X/Y, compositor). See [`hardware.md`](../../docs/hardware.md).

## What it is

Industry-standard **22V10** architecture PLD: programmable AND array, fixed OR with **variable product terms**, **10 macrocells**. Each macrocell can be **combinatorial or registered**, active high/low, with OE. Global **CLK** (pin 1), async reset / sync preset terms. Flash-based, reprogrammable, pin-keepers on inputs/I/O.

## Retr01 role

| Refdes | Job (HC573-zero) |
|--------|------------------|
| UPLDA | Address decode: RAM / cart / `$FExx` SEL, PHI2 gating |
| UPLDB | VRAM interleave glue + HC245 enables + **scroll X** register (`$FE02`) |
| UPLDX | Beam X / dot + **scroll Y** register (`$FE03`) |
| UPLDY | Beam Y + **raster Y** register (`$FE04`) + compare -> IRQB |
| UPLDV | Compositor priority + Color PROM index + **CART_A14-A18** MAP export |

**Registered load path:** clock enable = Decode `SEL_FExx` AND write cycle (RWB low, PHI2 high). Data = CPU D[7:0]. Scroll/raster use **24** flip-flops across UPLDB/UPLDX/UPLDY (10 FF each). Fitter escape: 1-2 discrete latches or +1 ATF22V10.

See [`graphics.md`](../../docs/graphics.md#fexx-ownership-hc573-zero).

## Resources (sim / fit)

| Resource | Count / note |
|----------|----------------|
| Macrocells | **10** (each = OR + OLMC + FF option) |
| Product terms / macrocell | **8, 10, 12, 14, 16, 16, 14, 12, 10, 8** (edges skimpiest) |
| Dedicated inputs | ~12 + CLK |
| Bidirectional I/O | 10 |
| Speed (C-5 grade) | `tPD` ~**5 ns**, `tCO` ~**4 ns**, `fMAX` >100 MHz |

Dot clock ~5.37 MHz and CPU 8 MHz are easy for this silicon. **fit** (product terms, I/O count) is the real limit.

## How it works

1. Designer writes equations (CUPL / WinCUPL / similar) -> JEDEC fuse file. Bench tools: [`programming.md`](../../docs/programming.md).
2. Each output = OR of its product terms (ANDs of true/complement inputs + feedbacks).
3. Registered mode: D FF clocks on pin-1 CLK rising edge. Combinatorial mode bypasses FF.
4. Pin-keepers hold last level if undriven (do not leave critical nets floating in sim without modeling keepers or pullups).

### Expected behavior (unit / fixture)

| Setup | Expect |
|-------|--------|
| Programmed as AND of two inputs -> out | Truth table matches equation |
| Registered counter bit | Toggles on CLK when enable equation true |
| Unprogrammed / blank | Treat as undefined: always load JEDEC in sim |

## Communication on Retr01

```text
CPU A[15:0], RWB, PHI2, RESB  -->  ATF22V10 (decode)
                                  -->  CE# / SEL_FE* to SRAM / flash / MCUs / PLD regs
CPU D + SEL_FE02/03/04          -->  registered scroll X/Y + raster Y (internal)
Beam / PPUCTRL soft             -->  ATF22V10 (timing / video)
                                  -->  HC157 selects, VRAM OE, IRQ hints, CART_A14-18
```

Exact pin equations are **board-specific** (not in this doc). Target sim: per-chip **equation tables** or JEDEC. Phase-1 sim uses **behavioral shells** (below).

## Simulator mapping (Phase-1)

Authority for *silicon* remains the vendor datasheet + JEDEC equations. The board sim (`app/sim`) mounts ATF22V10-class entities - not a fuse engine. Map to the **5 BOM PLDs**:

| BOM role ([`hardware.md`](../../docs/hardware.md)) | Sim entity / file | Behavior |
|-----------------------------------------------------|-------------------|----------|
| Address decode | `pld_decode` (`atf22v10.c`, role DECODE) | `$FExx` page decode -> `SEL_FE*` outputs. Sim still pulses HC573 LE (lag) |
| VRAM interleave / glue | `pld_vram` (`atf22v10.c`, role VRAM) | Visible I->Y stub. **interleave still in `wire_vram`**. Silicon adds scroll X regs |
| X-beam (0-340) | `pld_beam_x` (`beam_xy.c`) | Combined **X+Y** counters, HBlank/VBlank, **NMI#**. Silicon adds scroll Y regs |
| Y-beam + raster compare | `pld_beam_y` (`atf22v10.c`, role BEAM_Y) | **P==Q -> EQ#**. Silicon: Q registered inside PLD. Sim still peeks HC573 FE04 |
| Compositor priority mux | `compositor.c` | API-driven BG/sprite -> 6-bit Color PROM index. Silicon also exports CART_A14-18 |

**HC573 path (sim lag):** sim still models nine HC573 for FE02-04/08/10-11/90-92. Silicon: scroll/raster in PLDs, soft ports on 1284, CART_A14-18 on UPLDV. Caches sync from `peek_q` until sim follow-up.

**Flash /CE:** PRG, MAP (`$FE93`), and CHR are mutually exclusive. DOT / HBlank windows yield flash for CHR. If denied, `chr_last_master` holds.

**Behavioral (not a 6th BOM package):** `bg_fetch.c` - nametable VA from beam+scroll. Folds into VRAM PLD on silicon.

Do **not** treat these as JEDEC-accurate. Escape hatch: +1 PLD if fit fails ([`hardware.md`](../../docs/hardware.md)).
