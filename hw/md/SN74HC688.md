# SN74HC688 -- 8-bit identity comparator

**PDF:** [`../SN74HC688_comparator.pdf`](../SN74HC688_comparator.pdf).  
**Package:** 20-pin PDIP.  
**Qty (v0):** **1** -- raster Y compare.  
**Qty (v1):** **0** -- compare moves into Y-beam ATF22V10.  
**Typical `tpd`:** ~14 ns @ 5 V.

## What it is

Compares two 8-bit words **P[7:0]** and **Q[7:0]**. Active-low output **P=Q** is low when equal **and** OE is low. OE high forces **P=Q** high (inactive).

## Retr01 role

Raster IRQ: beam **Y** (or low 8 bits of line counter) vs latched **`$FE04`** raster value. Match -> pull **IRQB** (via glue/PLD).

```text
HC161 Y counter bits --> P[]
$FE04 HC573 Q outs   --> Q[]
HC688 P=Q# -----------> IRQ path
```

## 20-pin PDIP (signal names)

Standard layout (confirm against PDF figure when wiring):

| Side | Signals |
|------|---------|
| Controls | OE, P=Q output |
| Word P | P0..P7 |
| Word Q | Q0..Q7 |
| Power | VCC, GND |

Exact pin numbers: use datasheet Fig pinout when drawing schematics; sim model only needs P[], Q[], OE, P=Q#.

## Function

| OE | P == Q | P=Q# |
|----|--------|------|
| H | X | H |
| L | yes | **L** |
| L | no | H |

## Expected I/O

| Stimulus | Expect |
|----------|--------|
| OE=L, P=Q=`$64` | P=Q# low |
| P changes | Output high until equal again |
| OE=H | Output high (IRQ masked at comparator) |

## Sim notes

Combinational equality; optional tiny `tpd` delay. v1 deletes this chip from the netlist.
