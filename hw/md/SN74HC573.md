# SN74HC573A -- Octal transparent latch

**PDF:** [`../SN74HC573_latch.pdf`](../SN74HC573_latch.pdf).  
**Package:** 20-pin PDIP.  
**Qty (current):** **9** -- bit-packed `$FExx` ([`06`](../../docs/06_hardware_v1_32ic.md)).  
**Qty (legacy ~52):** **14**.  
**Typical `tpd`:** ~21 ns @ 5 V. 3-state Q outputs.

## What it is

Eight **D latches** with common **LE** (latch enable) and common **OE** (output enable, active low). While LE is **high**, Q follows D (**transparent**). When LE goes **low**, Q holds. OE high = Q Hi-Z.

## Retr01 role

Hold CPU-written I/O state that hardware reads continuously:

| Examples | Port (see `02`) |
|----------|-----------------|
| Scroll X/Y | `$FE02`/`$FE03` |
| PPUCTRL, raster Y | `$FE00`, `$FE04` |
| MAP address bytes | `$FE90`-`$FE92` |
| Bank helpers, WORLD, etc. | `$FE30`-`$FE38` |

Decode PLD pulses LE (or qualifies write) when `STA $FExx` hits that latch; OE often tied active so beam/PLD always see Q.

## 20-pin PDIP

```text
         +-----\/-----+
     OE  | 1       20 | VCC
     1D  | 2       19 | 1Q
     2D  | 3       18 | 2Q
     3D  | 4       17 | 3Q
     4D  | 5       16 | 4Q
     5D  | 6       15 | 5Q
     6D  | 7       14 | 6Q
     7D  | 8       13 | 7Q
     8D  | 9       12 | 8Q
    GND  |10       11 | LE
         +------------+
```

## Function

| OE | LE | Q |
|----|----|---|
| H | X | Hi-Z |
| L | H | Q = D (live) |
| L | L | Q = last D when LE fell |

## Expected I/O

| Stimulus | Expect |
|----------|--------|
| OE=L, LE=H, D=`$A5` | Q=`$A5` |
| LE -> L, then D changes | Q stays `$A5` |
| `STA $FE02` smoke (island D) | Only that latch updates |

## Communication

```text
CPU D[7:0] --> Dn
decode --> LE (write strobe), OE
Qn --> scroll counters / PLD / MAP addr / raster compare inputs
```
