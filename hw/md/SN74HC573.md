## What it is

Eight **D latches** with common **LE** (latch enable) and common **OE** (output enable, active low). While LE is **high**, Q follows D (**transparent**). When LE goes **low**, Q holds. OE high = Q Hi-Z.

## Retr01 role (historical)

Previously held CPU-written I/O that hardware read continuously (nine chips U5A-U5I).

**Silicon now:**

| Former ports | New owner |
|--------------|-----------|
| `$FE02` / `$FE03` / `$FE04` | Registered inside UPLDB / UPLDX / UPLDY |
| `$FE00` / `$FE05` / `$FE08` / `$FE90`-`$FE92` | ATmega1284P soft registers |
| `CART_A14`-`A18` | UPLDV registered MAP export |

**Sim:** still instantiates nine HC573 entities as behavioral mirrors (runner lag). Do not add them back to the schematic BOM.
