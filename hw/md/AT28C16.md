# AT28C16: Color PROM (legacy note)

> **Superseded on Retr01-A/C by [`AT27C256R.md`](AT27C256R.md)** (45 ns OTP). Kept for sim model name and packing reference.

**Package (Retr01 motherboard):** 24-pin PDIP.  
**Qty:** **1** (packed R3-G3-B2). Earlier sketches used **3** (R/G/B).  
**Organization:** **2K x 8** (16 Kbit). Retr01 uses only **64** entries (6-bit master index).

## Package dimensions

| | |
|--|--|
| Outline | PDIP-24, 600 mil |
| Body (nom.) | **32 x 14 mm** (length x width) |
| Sim @ 4 px/mm | **128 x 56 px** horizontal (default) |
| Reference | [`packages_dip.md`](packages_dip.md) |

## What it is

5 V parallel EEPROM, JEDEC byte-wide pinout. On Retr01 it is programmed **once** (or rarely) as a **Color PROM**: address = palette index, data = DAC code(s). During play it is **read-only** on the **video path**, not on the 6502 data bus.

## Retr01 role

| Topic | Spec |
|-------|------|
| Master palette | **64 colors** (indices 0-63) |
| Cart contents | Palette **indices only**: no RGB in `.retr01` |
| Active game pals | `$FE08`/`$FE09` load 4 BG + 4 sprite slots from the selected palette row -> these indices |
| Current wiring | One chip: data = `{RRRGGGBB}` to three ladders ([`hardware.md`](../../docs/hardware.md)) |
| Earlier sketches | Three chips: same address (index), separate R/G/B into R-2R DACs |

Access must meet **dot clock** (~5.37 MHz, ~186 ns/pixel). Part is **150 ns** `tACC`: plan **1-dot pipeline** (latch index, PROM out next pixel) if path is tight (see Q15 / faster OTP candidate AT27C256R).

## Capacity / speed

| Item | Value |
|------|-------|
| Array | **2048 x 8** (only 64 used for palette) |
| Read `tACC` / `tCE` | **150 ns** max (AT28C16-15) |
| `tOE` | 10-70 ns |
| Byte write `tWC` | 0.5-1.0 ms (standard). **E** option 100-200 us |
| Endurance | 10k or 100k (E) |
| VCC | 5 V +/- 10% |

## 24-pin PDIP pinout

```text
         +-----\/-----+
     A7  | 1       24 | VCC
     A6  | 2       23 | A8
     A5  | 3       22 | A9
     A4  | 4       21 | WE
     A3  | 5       20 | OE
     A2  | 6       19 | A10
     A1  | 7       18 | CE
     A0  | 8       17 | I/O7
    I/O0 | 9       16 | I/O6
    I/O1 |10       15 | I/O5
    I/O2 |11       14 | I/O4
    GND  |12       13 | I/O3
         +------------+
```

Retr01 palette: drive **A5-A0** (or A0-A5) with 6-bit index. Tie unused address lines to fixed levels. WE held **high** in play (read-only).

## Operating modes (play vs program)

| Mode | CE | OE | WE | I/O |
|------|----|----|----|-----|
| **Read** (play) | L | L | H | DOUT = PROM[addr] |
| Write (factory) | L | H | L | DIN, then busy `tWC` |
| Standby | H | X | X | Hi-Z |
| Output disable | X | H | X | Hi-Z |

DATA polling on I/O7 during write (complement until done). Chip erase / ID mode use **12 V** on OE or A9: **bench programmer only**, not on the game board during play.

## Expected I/O (unit tests)

| Stimulus | Expect |
|----------|--------|
| Addr = i (0..63), CE=OE=L, WE=H | I/O = programmed RGB code for color i |
| CE or OE high | I/O Hi-Z |
| Index steps every dot (piped) | Stable DAC codes with 1-pixel latency if modeled |

## Communication on Retr01

```text
Compositor / palette index (6 bit)
        |
     A[5:0]  (+ CE/OE from video timing)
        |
   AT28C16 x3 (v0) or x1 (v1)
        |
     R-2R (+75R) --> RGBS pads
```

No connection to W65C02S D-bus during play. Programming is off-line or a dedicated ISP path.

## Sim notes

- Model as **64-entry ROM** (+ optional full 2K array).
- Factory write path optional until Color PROM burn tooling exists.
- Match Studio Color PROM preview to the same packing (v0 three guns vs v1 R3G3B2).
