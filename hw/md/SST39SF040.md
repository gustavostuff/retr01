## What it is

5 V parallel NOR Multi-Purpose Flash. JEDEC command set. **Read** like ROM (CE# + OE# low, WE# high). **Program / erase** need multi-cycle software sequences (not a single WE# store like SRAM). Uniform **4 KB sectors**.

## Retr01 role

Holds the **`.retr01` cart image**: PRG + CHR + MAP (+ pals/dirs) in one 512 KB space.

| Region (CPU / fetch) | Access |
|----------------------|--------|
| PRG | Mapped `$8000+` (**32 KB**, no banking). I/O hole at `$FE00-$FEFF` |
| MAP | `$FE90-$FE93` seek + read |
| CHR | BG / sprite fetch from cart (not in VRAM) |

v0: chip on motherboard socket. Same image later moves to cart PCB.

Full fill at 8-world playfield caps (32 screens/world) + **32 KB** PRG = **429300 B** (~**419.2 KB**); **94988 B** (~**92.8 KB**) free ([`02`](../../docs/02_graphics_worlds_memory.md)).

## Capacity / speed

| Item | Value |
|------|-------|
| Size | **512 KB** (A18..A0) |
| VCC | **4.5-5.5 V** |
| Read access | **55 ns** or **70 ns** grade (`TAA`) |
| Sector size | **4 KB** |
| Byte program | typ 14 us, max ~20 us (`TBP`) |
| Sector erase | typ 18 ms |
| Chip erase | typ 70 ms |
| Endurance | typ 100k cycles |

CPU at 8 MHz needs PRG/MAP reads within the PHI2 window. **55 ns** grade is preferred. Programming is for **Studio burn / ISP**, not frame-rate writes.

## Device operation (sim-critical)

### Read

CE#=L, OE#=L, WE#=H -> DQ = flash[addr] after `TAA`. Either CE# or OE# high -> DQ Hi-Z.

### Byte program (4 write cycles)

| Step | Address | Data |
|------|---------|------|
| SW0 | `5555H` | `AAH` |
| SW1 | `2AAAH` | `55H` |
| SW2 | `5555H` | `A0H` |
| BYTE | program addr | data byte |

Then wait internal `TBP`. Poll DQ7 (Data#) or toggle bit until done.

### Chip erase (6 cycles)

`AA/55/80` at `5555`, then `AA/55`, then **`10H`** at `5555`. Wait `TSCE`. Array -> `FFH`.

### Sector erase (6 cycles)

Same unlock through `AA/55`, then **`30H`** at **sector address SAx** (A18-A12 select sector). Wait `TSE`.

Commands are written with CE# low and WE# pulsed. Address latched on falling WE#/CE#, data on rising.

## Expected I/O (unit tests)

| Stimulus | Expect |
|----------|--------|
| Read mode, known image | Correct bytes at PRG/MAP/CHR offsets |
| Incomplete command seq | No accidental program |
| Full program seq + poll | Byte changes, busy then ready |
| CE# high | DQ Hi-Z, no bus fight with other memories |

## Communication on Retr01

```text
W65C02S / BG fetch / 1284 CHR
        |
     addr + DQ + RWB decode
        |
   PLD gates CE# for PRG vs CHR vs MAP windows
        |
   SST39SF040
```

Only one of PRG/CHR/MAP chip-enable contexts at a time (island **J** smoke: one `/CE` at a time).
