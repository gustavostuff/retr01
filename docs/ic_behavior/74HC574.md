# 74HC574 behavior

**74HC574** octal edge-triggered register. Retr01 qty **1**: **BG1 scroll X** at `$7F02`.

**Package:** 20-pin **DIP**. **Family:** 74HC, 5 V on Retr01. Typical `tCO` teens of ns @ 5 V.

**Board:** `../general/hardware.md`. Field ALE uses **74HC573** instead. The two roles stay distinct.

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **D0-D7** | IN | CPU **D[7:0]** |
| **CLK** | IN | Rising-edge clock. On Retr01: Compositor **`LE_7F02`** (load on `$7F02` write only) |
| **/OE** | IN | Active-low output enable. Retr01 ties **/OE** low |
| **VCC** / **GND** | PWR | 5 V / GND |

No separate clock-enable pin (unlike 74HC377). Decode must only pulse CLK on a real `$7F02` write.

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| Rising CLK while D=N | Q becomes N after `tCO` |
| CLK idle, D changes | Q holds |
| /OE high | Q Hi-Z (not used on baseline) |

---

## 2. Process (what happens inside)

Eight D flip-flops sharing one rising-edge **CLK** and one **/OE**.

### Retr01 role

Holds **BG1 scroll X** so the Compositor ATF22V10 can keep **MAP A14-A18** without a 13-FF collision on one 22V10.

| Net | Connection |
| --- | --- |
| D0-D7 | CPU D[7:0] |
| CLK | `LE_7F02` |
| /OE | GND |
| Q0-Q7 | SX[7:0] to BG VA / beam path |

Same-cycle hard register timing as a PLD FF. **Do not** clock from free-running PHI2.

Scroll Y (`$7F03`) and raster Y (`$7F04`) stay inside Beam X / Beam Y PLDs.

## Sim notes

- Capture D into Q on rising CLK only.
- Pin names: `"D0"`, `"Q0"`, `"CLK"`, `"/OE"`.
- Related: field ALE latch is `74HC573.md`. PLD that makes `LE_7F02` is `ATF22V10.md` (Compositor).
