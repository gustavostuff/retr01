# W65C02S behavior

Western Design Center **W65C02S** 8-bit microprocessor. Retr01 uses it as the only game CPU.

**Board role:** `../hardware.md` (8.000 MHz PHI2). **CPU map:** `../memory.md`.

## What it is

| Topic | Spec / Retr01 |
| --- | --- |
| Data / address | 8-bit data, 16-bit address (64 KB space) |
| ISA | 70 instructions, 16 addressing modes, 212 opcodes |
| Core | Fully static. PHI2 may be held high or low without losing register state |
| Supply | Specified across several rails including **5.0 V +/- 5%** (Retr01 is 5 V TTL/CMOS friendly) |
| Package on Retr01 | Through-hole DIP path (40-pin PDIP available for this part). Match the BOM footprint when laying out |

Extra WDC signals vs a plain NMOS 6502 that matter here: **VPB**, **BE**, **MLB**, **SYNC**, **RDY** (bi-directional with WAI), **WAI** / **STP**.

## Clocks

| Signal | Behavior |
| --- | --- |
| **PHI2** | Required system clock input. All production timing is based on PHI2 |
| **PHI2O** / **PHI1O** | Derived outputs. WDC recommends an external oscillator for PHI2 and system time base. Do not rely on PHI2O/PHI1O as the master clock |
| Retr01 | **8.000 MHz** into PHI2. Same edge family used to mux interleaved VRAM (CPU owns the bus on PHI2 high, beam on PHI2 low). See `../hardware.md` |

## Bus pins (behavior)

| Pin | Direction | Behavior |
| --- | --- | --- |
| A0-A15 | Out (hi-Z if BE low) | Address of the current cycle |
| D0-D7 | In/out (hi-Z if BE low) | Data. Valid per RWB and PHI2 phase |
| **RWB** | Out (hi-Z if BE low) | High = read. Low = write |
| **BE** | In | High = address/data/RWB buffers active. Low = those buffers hi-Z (DMA / external master style use) |
| **SYNC** | Out | High during an opcode fetch cycle |
| **MLB** | Out | Memory lock for read-modify-write integrity when shared memory is present |
| **VPB** | Out | Low while the CPU is addressing an interrupt/reset vector location |

Retr01 decode and PLDs watch address + RWB (+ soft SEL from the AVRs). BE stays high in normal play unless a future DMA story needs it.

## Interrupts and reset

| Pin | Sense | Vector (lo, hi) | Notes |
| --- | --- | --- | --- |
| **RESB** | Level, then rising edge starts reset | `$FFFC`, `$FFFD` | Hold low long enough through power-up. After release, a multi-cycle reset sequence loads PC from the vector |
| **NMIB** | Edge (negative transition) | `$FFFA`, `$FFFB` | Edge sensitive. Staying low does not keep re-firing |
| **IRQB** | Level low | `$FFFE`, `$FFFF` (also BRK) | Masked by the I flag. Keep IRQB asserted until the handler clears the source if you want a clean re-arm |

Retr01 beam PLDs drive **NMI** (VBlank) and **IRQ** paths as described in `../hardware.md` (Beam X / Beam Y). Vectors live in the top of the contiguous PRG image at `$8000-$FFFF`.

## Ready (RDY)

| Topic | Behavior |
| --- | --- |
| Input low | Halts the CPU in its current state (setup to the falling PHI2 edge must be met). Address lines keep showing the current fetch address |
| Return high | Continues after the next PHI2 falling edge |
| Bi-directional | **WAI** pulls RDY low to advertise wait-for-interrupt. External logic must allow that |

Retr01: **MCU-M** asserts `CPU_RDY` low while cart EEPROM or machine EEPROM transactions complete (and similar slow helpers). Soft `$7Fxx` mailboxes that need a stall use this path. Do not leave RDY floating.

## Reset and start of PRG

1. RESB released.
2. CPU loads PC from `$FFFC/$FFFD` inside cart flash PRG.
3. Code runs from the flat 32 KB PRG window (`$8000-$FFFF`). I/O is **`$7F00-$7FFF`**, not punched out of PRG.

## What PRG owns on Retr01

- Game logic and **entity behavior** (C/ASM).
- Streaming MAP bytes via `$7F90-$7F93` and VRAM via `$7F10-$7F12` on CPU phases.
- Talking to MCU-M soft ports (OAM mailbox, pads readback, APU mailbox, palette row, saves).

What it does **not** own: per-dot video, sprite field fill (MCU-S1), pad sampling hardware (MCU-S2).

## Caveats to respect

- Meet RDY and interrupt setup/hold to PHI2. Stretching the clock with RDY is how slow I2C EEPROM looks atomic to game code.
- Prefer PHI2 from a crystal oscillator module. Treat PHI1O/PHI2O as legacy.
- Stack lives in system RAM (`$0100-$01FF` by convention). Size the stack for NMI + IRQ nesting used by the game.
