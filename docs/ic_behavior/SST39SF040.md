# SST39SF040 behavior

Microchip / SST **SST39SF040** parallel NOR flash. Retr01 cart image storage (qty **1** on the cartridge).

**Package:** 32-pin **PDIP** (600 mil). **Organization:** **512K x 8** (4 Mbit). **VCC:** 5 V.

Sibling parts SF010A / SF020A are smaller. Retr01 uses **SF040** so **A18** and **A17** are real.

**Board:** `../general/hardware.md`. **Cart:** `../general/cartridge.md`. **Image:** `../general/memory.md`.

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **A18-A0** | IN | Byte address (19 bits = 512 KB) |
| **DQ0-DQ7** | IO | On **command / program**: host drives data while WE# pulses |
| **CE#** | IN | Chip enable. Cart ties CE# **active** (always selected when powered). Mobo still gates bus use via OE# |
| **OE#** | IN | Output enable (read). Motherboard gates this |
| **WE#** | IN | Write enable (command / program). Idle high in normal play. Console flash path drives it |
| **VDD** / **VSS** | PWR | 5 V / GND |

### Retr01 address sources

| Bits | Source |
| --- | --- |
| **A0-A13** | CPU address bus |
| **A14-A18** | Compositor MAP port (cart MAP seek / CHR banks) |

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| CE#=L, OE#=L, WE#=H, known image | DQ = flash[addr] after `TAA` |
| Incomplete command seq | No accidental program |
| Full byte-program seq + poll | Byte changes, busy then ready |
| OE# high (or CE# high) | DQ Hi-Z, no fight with RAM / MCU-M |

## 2. Process (what happens inside)

5 V Multi-Purpose Flash. JEDEC software command set. Uniform **4 KB** sectors.

### Capacity / speed

| Item | Value |
| --- | --- |
| Size | **512 KB** (A18..A0) |
| Read access | **55 ns** or **70 ns** grade (`TAA`). Prefer **55 ns** at 8 MHz |
| Byte program | typ 14 us, max ~20 us (`TBP`) |
| Sector erase | typ 18 ms |
| Chip erase | typ 70 ms |
| Endurance | typ 100k cycles |

CPU PRG/MAP reads must close the PHI2 window. Programming is the **console flash path** (MCU-M bridge + Adafruit's UPDI Friend), not frame-rate writes.

### What the cart image holds

`.retr01` layout: header, pals, **32 KB PRG**, global CHR (16 banks), entity catalog, other screens, up to **8** world blobs (maps only), compressed BGM. See `../general/memory.md`.

| Region | Access path |
| --- | --- |
| **PRG** | CPU `$8000-$FFFF` (flat 32 KB, no banking) |
| **MAP** | `$7F90-$7F93` seek + data |
| **CHR** | Video / helper fetch by bank+index (not in the 6502 map) |

### Read

CE#=L, OE#=L, WE#=H -> DQ = flash[addr] after `TAA`. Either CE# or OE# high -> DQ Hi-Z.

### Byte program (4 write cycles)

| Step | Address | Data |
| --- | --- | --- |
| SW0 | `5555H` | `AAH` |
| SW1 | `2AAAH` | `55H` |
| SW2 | `5555H` | `A0H` |
| BYTE | program addr | data byte |

Then wait internal `TBP`. Poll DQ7 (Data#) or toggle bit until done.

### Chip erase (6 cycles)

`AA/55/80` at `5555`, then `AA/55`, then **`10H`** at `5555`. Wait `TSCE`. Array -> `FFH`.

### Sector erase (6 cycles)

Same unlock through `AA/55`, then **`30H`** at **sector address SAx** (A18-A12 select sector). Wait `TSE`.

Commands are written with CE# low and WE# pulsed. Address latches on falling WE#/CE#, data on rising. Address `5555H`/`2AAAH` are **device** address bits, not CPU `$5555`.

### Where it sits on Retr01

```text
W65C02S A[13:0] + Compositor MAP A[18:14]
        |
     DQ + OE# (mobo gated) + WE# (flash path)
        |
   SST39SF040 on cart
```

PRG, MAP, and CHR chip-enable contexts stay mutually exclusive. Only one bus driver on cart DQ at a time.
