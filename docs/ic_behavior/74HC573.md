# 74HC573 behavior

**74HC573** octal transparent latch. Retr01 qty **1**: field SRAM **A[7:0]** latch (ALE from MCU-S1).

**Package:** 20-pin **DIP**. **Family:** 74HC, 5 V on Retr01.

**Board:** `../general/hardware.md`. Distinct from **74HC574** (edge-triggered scroll X).

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **D0-D7** | IN | Latch data. On Retr01: MCU-S1 **AD[7:0]** |
| **LE** | IN | Latch enable (active high). On Retr01: MCU-S1 **ALE** |
| **/OE** | IN | Output enable (active low). Retr01 ties **/OE** low |
| **VCC** / **GND** | PWR | 5 V / GND |

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| LE=H, D=N | Q follows N (transparent) |
| LE falls while D=N | Q holds N |
| LE=L, D changes | Q unchanged |
| /OE=H | Q Hi-Z (not used on baseline Retr01) |

---

## 2. Process (what happens inside)

Eight transparent D latches sharing one **LE** and one **/OE**.

| LE | Behavior |
| --- | --- |
| **H** | Q follows D (transparent) |
| **L** | Q holds last value |

### Retr01 field write sequence

1. MCU-S1 places A[14:8] on upper address pins and A[7:0] on AD.
2. Pulse **ALE** high then low so HC573 captures A[7:0] onto field A[7:0].
3. Place data on AD.
4. Pulse **`/WE`** into AS6C62256 #3.

S1 drives ALE + `/WE` only. `/OE`/`/CE` for the field SRAM come from the PLD.

## Sim notes

- Phase 1: when LE high, `latched = D`. When LE low, hold. Drive Q if /OE low.
- Pin names: `"D0"`, `"Q0"`, `"LE"`, `"/OE"`.
- Clock is ALE from MCU-S1 only, never free-running PHI2.
