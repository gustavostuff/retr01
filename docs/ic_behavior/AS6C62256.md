# AS6C62256 behavior

Alliance / JEDEC-style **AS6C62256** (32K x 8 CMOS SRAM). Retr01 uses **three** PDIP-28 parts at **55 ns** grade (AS6C62256-55 preferred).

| Instance | Job |
| --- | --- |
| **#1 System RAM** | CPU `$0000-$7EFF` |
| **#2 VRAM** | Interleaved nametable / attribute RAM (CPU vs beam) |
| **#3 Field** | Sprite field (VBlank fill) + BG0 ping-pong line buffers (HBlank fill) |

Same silicon. Decode / mux / ALE wiring differ. **Board:** `../general/hardware.md`. **Map:** `../general/memory.md`.

**Package:** 28-pin **PDIP** (600 mil). **VCC:** 5 V on Retr01.

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **A0-A14** | IN | Byte address (15 bits = 32 KB) |
| **DQ0-DQ7** | IO | On **write**: external driver must present data while WE# is low |
| **CE#** | IN | Active-low chip enable |
| **OE#** | IN | Active-low output enable (reads) |
| **WE#** | IN | Active-low write enable |
| **VCC** / **VSS** | PWR | 5 V / GND |

### What each Retr01 instance listens to

| Instance | Address / control source |
| --- | --- |
| **#1 System** | CPU A[14:0] + PLD CE#/OE#/WE# from RWB and `$0000-$7EFF` decode |
| **#2 VRAM** | 3x **74HC157** mux of CPU vs beam A[11:0] (extend upper bits as board needs). PLD CE#/OE#. PHI2 high = CPU `$7F10-$7F12`. PHI2 low = BG fetch |
| **#3 Field** | MCU-S1 AD[7:0] + A[14:8], **74HC573** latched A[7:0] from ALE. S1 drives `/WE`. PLD `/OE`/`/CE` |

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| CE#=H | DQ Hi-Z |
| CE#=L, OE#=L, WE#=H, addr=N | DQ = mem[N] after access delay |
| CE#=L, WE#=L, DIN=X, addr=N | mem[N] = X after write cycle |
| Addr change while selected for read | New data after `tAA`. Hold old `tOH` >= 10 ns |

---

## 2. Process (what happens inside)

Async SRAM. No clock pin. Fully static. Array is **32,768 x 8**.

### Truth table

| Mode | CE# | OE# | WE# | DQ |
| --- | --- | --- | --- | --- |
| Standby | H | X | X | Hi-Z |
| Output disable | L | H | H | Hi-Z |
| **Read** | L | L | H | DOUT |
| **Write** | L | X | L | DIN |

On write, hold OE# high while the writer drives DQ so two drivers do not fight.

### Timing (AS6C62256-55)

| Item | Value |
| --- | --- |
| Density | 256 Kbit = 32 KB |
| `tAA` / `tACE` / `tRC` / `tWC` | **55 ns** max / min as rated |
| `tWP` | min **45 ns** |
| `tOE` | **30 ns** from OE# |
| `tDW` | data setup >= **25 ns** before WE#/CE# end |
| `tDH` | hold >= **0** |

At **8 MHz** PHI2 (125 ns) and **~5.37 MHz** dot (~186 ns), 55 ns SRAM has margin if decode + mux stay under ~70 ns.

### What Retr01 stores here

| Instance | Contents |
| --- | --- |
| **#1** | Zero page, stack, entity state, game RAM |
| **#2** | VRAM nametables / attrs behind `$7F10-$7F12` |
| **#3** | Full sprite field buffer + BG0 next-line ping-pong |

Not inside this IC: address mux, ALE latch, or bus decode. Those are HC157 / HC573 / PLDs.

| Pin | Dir | What the chip drives |

| **DQ0-DQ7** | IO | On **read** (CE#=L, OE#=L, WE#=H): array data. Else Hi-Z |

### Three chips on the netlist

```text
System RAM:  CPU A/D/RWB + decode CE#  ------------------> AS6C62256 #1
VRAM:        HC157 mux (CPU vs beam addr) + PLD CE#/OE# --> AS6C62256 #2
Field:       MCU-S1 AD + HC573 ALE + PLD /OE /CE --------> AS6C62256 #3
```

Register the same part string (`"AS6C62256"`) three times with different refdes. One driver on DQ at a time.

---

## Sim notes

- Phase 1: combinational after delay from CE#/OE#/WE#/addr edges. Tighten to 55 ns numbers later.
- Pin names should match the table (`"A0"`, `"CE#"`, `"DQ0"`, ...).
- Model three independent 32 KB arrays. Instances do not share state.
