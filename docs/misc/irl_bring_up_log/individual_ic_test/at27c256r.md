# AT27C256R color PROM

Used in Tiers A, B, and C.

The socket holds the 64-byte kit image. This check uses jumpers on A5 through A0. No PLD is required.

## Read-mode ties

Pin 28 is VCC. Pin 14 is GND. Pin 1 (VPP) and pin 27 (PGM#) tie to 5 V. Pin 20 (CE#) and pin 22 (OE#) tie to GND. Address pins A6 through A13 tie to GND.

| Address | Pin |
| --- | --- |
| A0 | 10 |
| A1 | 9 |
| A2 | 8 |
| A3 | 7 |
| A4 | 6 |
| A5 | 5 |
| A6 | 4 |
| A7 | 3 |
| A8 | 25 |
| A9 | 24 |
| A10 | 21 |
| A11 | 23 |
| A12 | 2 |
| A13 | 26 |

Data pins, least significant bit first: O0 pin 11, O1 pin 12, O2 pin 13, O3 pin 15, O4 pin 16, O5 pin 17, O6 pin 18, O7 pin 19. The byte is packed R3G3B2, so O7 is the top red bit and O0 is the bottom blue bit.

## Pass

A high address bit ties to 5 V. A low address bit ties to GND.

| Index | A5 to A0 | Data pins |
| --- | --- | --- |
| 0 | all low | every O pin low (byte 0x00) |
| 1 | only A0 high | only O5 (pin 17) high (byte 0x20) |
| 48 | A5 and A4 high, A3 to A0 low | every O pin high (byte 0xFF) |
| 63 | all high | O7, O6, O5, O4, O1, and O0 high. O3 and O2 low (byte 0xF3) |

CE# or OE# high releases the data pins. With a resistor from one O pin to ground, that pin sits low while the output is off, and it follows the table again when both enables return low.
