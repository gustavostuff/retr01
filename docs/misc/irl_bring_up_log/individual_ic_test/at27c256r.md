# AT27C256R color PROM

One kit chip in the socket at a time. The package is 600 mil, so it sits in a 28-pin socket of that width, one jumper per pin. The notch is pin 1. Power is off while the chip goes in or comes out. Pin 1 (VPP) ties to the same 5 V rail as pin 28 (VCC).

## Place

| What | Where |
| --- | --- |
| Pin 28 (VCC) and pin 1 (VPP) | +5 V |
| Pin 14 (GND) | Ground |
| 100 nF | Pin 28 to pin 14 |
| Pins 2, 3, 4, 21, 23, 24, 25, 26, 27 (A12, A7, A6, A10, A11, A9, A8, A13, A14) | Ground |
| Pin 20 (CE#) and pin 22 (OE#) | Ground |

A high on A14 selects the upper 16 KB. Those bytes are `0xFF`. CE# or OE# high turns the data pins off.

Each index pin gets a 10 kohm resistor to ground and a switch to +5 V. Closed is 1. Open is 0. A5 is the 32s bit.

| Pin | Bit |
| --- | --- |
| 5 | A5, weight 32 |
| 6 | A4, weight 16 |
| 7 | A3, weight 8 |
| 8 | A2, weight 4 |
| 9 | A1, weight 2 |
| 10 | A0, weight 1 |

Each data pin gets +5 V, then 2.2 kohm, then the LED anode. The cathode goes to the pin. A lit LED is a 0. A dark LED is a 1. Pin 14 is ground, so O2 is pin 13.

| Pin | Bit |
| --- | --- |
| 19 | O7, red weight 4 |
| 18 | O6, red weight 2 |
| 17 | O5, red weight 1 |
| 16 | O4, green weight 4 |
| 15 | O3, green weight 2 |
| 13 | O2, green weight 1 |
| 12 | O1, blue weight 2 |
| 11 | O0, blue weight 1 |

## Check

The switch code is the row number in [`apps/common/r01_kit_palette.c`](../../../../apps/common/r01_kit_palette.c), starting at 0. The PROM does not store those raw bytes. Each row becomes three small integers:

```text
red   = (R * 7 + 127) / 255    range 0 to 7
green = (G * 7 + 127) / 255    range 0 to 7
blue  = (B * 3 + 127) / 255    range 0 to 3
```

A dark LED is a 1 in that weight. A lit LED is a 0.

Index 0 is `{0x00, 0x00, 0x00}`. All eight LEDs light. Index 48 is `{0xFF, 0xFF, 0xFF}`. All eight LEDs stay dark.

Power off, then the second chip goes in with the notch at the same end. The same index lights the same LEDs.
