# ATF22V10 behavior

Microchip / Atmel **ATF22V10** electrically erasable PLD. Retr01 uses **three** PDIP-24 parts (planning class: ATF22V10CQZ-20PU, 5 V).

| Instance | Job |
| --- | --- |
| **Beam X** | Dot / H inside 341. Scroll Y `$7F03`. HBlank / VBlank / NMI |
| **Beam Y** | Line / V. Raster Y `$7F04` + cascaded EQ -> IRQB |
| **Compositor** | Priority, Color PROM index, MAP A14-A18. `LE_7F02`/`03`/`04`, `SEL_VRAM`, `LE_MAP`, three `SEL_SOFT*`, residual `/OE` |

Same silicon. Different JEDEC equations. Programmed **off the console** (no HV EDIT path on the motherboard).

**Board:** `../general_docs/hardware.md`. Escape if equations overflow: optional **+1** PLD (breaks the 17-mobo comfort if populated).

---

## 1. Inputs (what pins can sense)

Generic 22V10 pin classes (exact net per JEDEC file):

| Pin class | Dir | What the net must provide |
| --- | --- | --- |
| **CLK/IN** (pin 1) | IN | Global clock for registered macrocells (DOT or PHI2-related nets per role) |
| **Dedicated IN** | IN | CPU A/RWB/PHI2/RESB, beam feedbacks, layer pixel bits, compare buses |
| **I/O feedback** | IO | Macrocell feedback when used as input |
| **VCC** / **GND** | PWR | 5 V / GND |

### What each Retr01 role listens to (logical)

| Role | Typical inputs |
| --- | --- |
| **Beam X** | DOT clock, reset, scroll-Y load (`LE_7F03` + CPU D), H wrap terms |
| **Beam Y** | Line clock / cascade from X, raster compare load (`LE_7F04` + CPU D) |
| **Compositor** | CPU A[15:0], RWB, PHI2, RESB, layer pixels / priority, MAP seek bits |

Pin 4 can be **power-down (PD)** when that fuse feature is enabled. Leave unused.

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| Programmed AND of two inputs -> out | Truth table matches equation |
| Registered bit with clock enable | Toggles / loads on CLK when enable equation true |
| Blank / unprogrammed part | Treat as undefined. Always load JEDEC in sim |

## 2. Process (what happens inside)

Industry-standard **22V10** architecture:

1. Programmable AND array.
2. Fixed OR with **variable product terms** per macrocell.
3. **10** output logic macrocells (OLMC). Each can be combinatorial or registered, active high/low, with OE.
4. Global **CLK** (pin 1), async reset / sync preset terms.
5. Flash-based, reprogrammable. Pin-keepers on inputs/I/O.

### Resources

| Resource | Count / note |
| --- | --- |
| Macrocells | **10** |
| Product terms / macrocell | **8, 10, 12, 14, 16, 16, 14, 12, 10, 8** (edges skimpiest) |
| Dedicated inputs | ~12 + CLK |
| Bidirectional I/O | 10 |
| Speed (C-5 class) | `tPD` ~**5 ns**, `tCO` ~**4 ns**, `fMAX` >100 MHz |

Dot (~5.37 MHz) and CPU (8 MHz) are easy for this silicon. **Fit** (product terms, I/O count, FF placement) is the real limit.

Macrocell pressure note from `../general_docs/hardware.md`: SY(8)+Q(8)+MAP(5) = **21** vs **30** MC across three 22V10s. That budget is a hard limit when adding features.

### Registered load path (Retr01)

PLD clock enable = decode `LE_7Fxx` AND write cycle (RWB low, PHI2 high). Data = CPU D[7:0].

| Register | Where |
| --- | --- |
| Scroll Y `$7F03` | Beam X FFs |
| Raster Y `$7F04` | Beam Y FFs |
| MAP A14-A18 | Compositor FFs (**5**) |
| Scroll X `$7F02` | **Not** in a PLD. Uses **74HC574** |

Never route hard LE or beam through an MCU.

### How equations become silicon

Designer writes CUPL / WinCUPL / similar -> JEDEC fuse file. Bench tools: Arduino-based GAL programmers (e.g. Afterburner) or a TL866-class tool that lists ATF22V10. Buy pre-programmed parts for non-tinkerers.

## 3. Outputs (what pins can drive)

| Pin class | Dir | What the chip drives |
| --- | --- | --- |
| **I/O macrocells** | OUT / IO | Beam timing, NMI#/IRQB helpers, `LE_*`, `SEL_*`, `/OE`, Color PROM index bits, CART_A14-18, CSYNC/HSYNC/VSYNC toward J2 / AD724 |

### 24-pin DIP (sim pin table)

```text
         +-----\/-----+
 CLK/IN  | 1       24 | VCC
     IN  | 2       23 | I/O
     IN  | 3       22 | I/O
  IN/PD  | 4       21 | I/O
     IN  | 5       20 | I/O
     IN  | 6       19 | I/O
     IN  | 7       18 | I/O
     IN  | 8       17 | I/O
     IN  | 9       16 | I/O
     IN  |10       15 | I/O
     IN  |11       14 | I/O
    GND  |12       13 | IN
         +------------+
```

| Num | Name | Dir |
| --- | --- | --- |
| 1 | CLK/IN | IN |
| 2-11 | IN | IN |
| 12 | GND | PWR |
| 13 | IN | IN |
| 14-23 | I/O | IO |
| 24 | VCC | PWR |

Exact signal names are **board JEDEC**-specific. Sims should use logical net names (`"NMI#"`, `"LE_7F02"`, `"SEL_SOFT0"`, ...) wired to whichever physical I/O the fuse map assigns.

### Three chips on the netlist

```text
CPU A/D/RWB/PHI2 --> Compositor --> LE_7F02/03/04, SEL_SOFT*, SEL_VRAM, LE_MAP, /OE
CPU D + LE_7F02  --> 74HC574 scroll X
CPU D + LE_7F03  --> Beam X scroll Y
CPU D + LE_7F04  --> Beam Y raster, EQ --> IRQB
Beam / layers    --> Compositor --> Color PROM index + CART_A14-18
DOT / wrap       --> Beam X/Y --> HBlank, VBlank, NMIB
```

Register the same part string (`"ATF22V10"`) three times with different firmware/JEDEC (or different `eval` equation tables).

## Sim notes

- Phase 1: behavioral shells per role (beam counters, decode selects, compositor priority). Not a full fuse engine.
- Pin-keepers hold last level if undriven. Model keepers or pullups on critical nets.
- Always load equations / JEDEC intent before trusting outputs.
