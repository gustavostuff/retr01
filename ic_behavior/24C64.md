# 24C64 behavior

I2C serial EEPROM in the **24C64 / 24LC64** class (8K x 8). Retr01 cart **game saves** (qty **1** on the cartridge).

Vendor second-sources vary. This note covers the Retr01 role and a sim stub. Confirm the frozen datasheet for A0-A2 address and WP polarity.

**Package:** 8-pin **DIP** (typical). **Organization:** **64 Kbit**. **Bus:** I2C (SDA / SCL).

**Board:** `../general_docs/hardware.md`. **Cart:** `../general_docs/cartridge.md`. Machine settings are **not** here (MCU-M on-chip EEPROM via `$7F70-$7F72`).

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **A0, A1, A2** | IN | I2C device-address select (hardwired on cart) |
| **SDA** | IO | Open-drain data. Sense start/stop, address, write data |
| **SCL** | IN | I2C clock from MCU-M TWI master |
| **WP** | IN | Write protect (part-dependent). High usually inhibits writes |
| **VCC** / **GND** | PWR | 5 V / GND |

Cart edge carries **SDA** and **SCL** (see `../general_docs/hardware.md` 2x18 pinout). Host is **MCU-M** TWI0 on **PA2/PA3**.

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| Idle bus | SDA released (pull-up high on hardware) |
| Start + matching device address | Slave ACK |
| Write then readback | Same byte after internal write cycle |
| WP asserted (if wired) | Writes NACK or ignored per datasheet |

---

## 2. Process (what happens inside)

Serial EEPROM. Byte or page write with ACK polling. Internal charge pump programs the array after a write command. Reads are random or sequential over I2C.

### Retr01 role

| Topic | Spec |
| --- | --- |
| Location | **Cartridge** (one of the **2** cart ICs in the 19 count) |
| Contents | Per-game saves |
| Host | MCU-M I2C master |
| CPU mailbox | `$7F22-$7F24` (MCU-M soft ports) |
| Not this chip | Machine/cabinet config (`$7F70-$7F72` on MCU-M) |

Capacity is **8 KB**. Exact save layout is game software / Studio defined.

### Typical device address

7-bit base `1010` + A2 A1 A0 (confirm against chosen part). MCU-M firmware must match the cart wiring of A0-A2.

## 3. Outputs (what pins can drive)

| Pin | Dir | What the chip drives |
| --- | --- | --- |
| **SDA** | IO | Open-drain ACK and read data. Releases for pull-up high |

### 8-pin DIP (typical sim pin table)

```text
         +-----\/-----+
    A0   | 1        8 | VCC
    A1   | 2        7 | WP
    A2   | 3        6 | SCL
   GND   | 4        5 | SDA
         +------------+
```

| Num | Name | Dir |
| --- | --- | --- |
| 1 | A0 | IN |
| 2 | A1 | IN |
| 3 | A2 | IN |
| 4 | GND | PWR |
| 5 | SDA | IO |
| 6 | SCL | IN |
| 7 | WP | IN |
| 8 | VCC | PWR |

### Where it sits on Retr01

```text
6502 --soft $7F22-24--> MCU-M TWI0 --SDA/SCL--> 24C64 on cart
SST39SF040 parallel flash stays on a separate bus path
```

## Sim notes

- Phase 1: pin shell + 8 KB memory array stub. Full I2C state machine can come later.
- Do not treat a stub as protocol-correct silicon until cart-save HAL lands.
- Pin names: `"SDA"`, `"SCL"`, `"A0"`, `"WP"`, ...
