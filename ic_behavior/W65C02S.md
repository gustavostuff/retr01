# W65C02S behavior

Western Design Center **W65C02S**. Retr01 game CPU (qty **1**).

**Package:** 40-pin **PDIP**. **Clock:** PHI2 = **8.000 MHz**.  
**Board:** `../general_docs/hardware.md`. **Map:** `../general_docs/memory.md` (PRG `$8000-$FFFF`, I/O `$7F00-$7FFF`, RAM `$0000-$7EFF`).

It never paints a framebuffer. It runs game / entity **behavior**, streams MAP and VRAM on CPU phases, and talks to MCU-M soft ports.

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **PHI2** | IN | Master clock. Rising/falling edges pace every bus cycle |
| **RESB** | IN | Active-low reset. Hold low through power-up. Rising edge starts reset sequence |
| **IRQB** | IN | Level-low IRQ request (masked by I flag in P) |
| **NMIB** | IN | Falling-edge NMI request |
| **BE** | IN | Bus enable. **1** = A/D/RWB drivers on (Retr01 normal). **0** = those buffers Hi-Z |
| **RDY** | IO | As **input**: low stalls the CPU (setup to PHI2 fall). As **output**: WAI can drive low |
| **SOB** | IN | Legacy set-overflow. Falling edge can set V. **Unused on Retr01** (tie inactive) |
| **D0-D7** | IO | On **read** cycles (RWB=1): external device must drive data before PHI2 fall |
| **VDD** / **VSS** | PWR | 5 V / GND |

Retr01 sources: oscillator -> PHI2. Beam PLDs -> NMIB (VBlank) and IRQB (raster / EQ). MCU-M -> RDY during slow EEPROM / soft work. Decode does not need BE toggled in normal play (keep BE high).

### Stimulus checklist (for unit tests)

| Stimulus | Expect |
| --- | --- |
| RESB low then high, PHI2 running, BE=1, RDY=1 | After reset seq, read `$FFFC/$FFFD`, then fetch from that PC |
| IRQB low while I=0 | After current insn: push P/PC, set I, vector `$FFFE/$FFFF` |
| NMIB falling edge | After current insn: push P/PC, vector `$FFFA/$FFFB` |
| RDY low before PHI2 fall | CPU holds. Address stays on A |
| BE=0 | A, D, RWB go Hi-Z |

## 2. Process (what happens inside)

### Programming model

| Register | Width | Notes |
| --- | --- | --- |
| A | 8 | Accumulator |
| X, Y | 8 | Index |
| PC | 16 | PCH:PCL |
| S | 8 | Stack in page `$01xx` (high byte implied `1`) |
| P | 8 | Flags **N V 1 B D I Z C** (bit 5 always 1) |
| IR / TCU | internal | Opcode + cycle timing for the current instruction |

ISA: 70 instructions, 16 addressing modes, 212 opcodes. Fully static core (PHI2 may stop high or low without losing regs).

### Interrupt / reset vectors

| Vector | Addr | Source |
| --- | --- | --- |
| NMIB | `$FFFA/$FFFB` | Edge on NMIB |
| RESB | `$FFFC/$FFFD` | Reset |
| BRK/IRQB | `$FFFE/$FFFF` | BRK or IRQB |

Reset sequence lasts **7** PHI2 cycles after RESB release. Hardware clears D and sets I. Other regs need software init. Vectors live in cart PRG (top of `$8000-$FFFF`).

### One PHI2 cycle (functional)

1. **Falling PHI2:** new address, RWB, SYNC/MLB/VPB settle for the next phase.
2. **Read (RWB=1):** memory / I/O must present D before the next falling PHI2.
3. **Write (RWB=0):** CPU drives D after **rising** PHI2 and holds through the fall.
4. **Opcode fetch:** SYNC high that cycle. Address = PC.

At **8 MHz**, cycle time is **125 ns**. SRAM, cart, mux, and soft ports must close that window with decode delay included. Sims can start edge-functional, then add delay budgets.

### RDY / WAI / STP

- **RDY input low:** freeze in current state (address remains).
- **WAI:** CPU can pull RDY low to wait for interrupt. External RDY drivers must tolerate that (open-drain style on Retr01). WAI is only with a clear NMI/IRQ wake.
- **STP:** stops the clock domain internally. Unused in normal play.

### What Retr01 PRG does with this core

- Entity **behavior**, camera, game modes (C/ASM).
- MAP via `$7F90-$7F93`, VRAM via `$7F10-$7F12` on CPU phases only.
- Soft ports on MCU-M (OAM, pads mirror, APU mailbox, palette row, saves).

Not inside this IC: per-dot video, sprite field fill, pad debounce hardware.

## 3. Outputs (what pins can drive)

| Pin | Dir | What the chip drives |
| --- | --- | --- |
| **A0-A15** | OUT (Z if BE=0) | Current cycle address |
| **D0-D7** | IO | On **write** cycles: driven data. On read: Hi-Z (listening) |
| **RWB** | OUT (Z if BE=0) | **1 = read**, **0 = write** |
| **SYNC** | OUT | High during opcode fetch |
| **MLB** | OUT | Low during RMW modify/write (ASL, DEC, INC, TRB, TSB, ...) |
| **VPB** | OUT | Low while fetching interrupt/reset vectors |
| **PHI1O** / **PHI2O** | OUT | Legacy derived clocks. **Do not** use as system time base |
| **RDY** | IO | May drive low during WAI |

### Where outputs go on Retr01

```text
W65C02S  A[15:0], D[7:0], RWB, PHI2, SYNC, VPB, MLB
    |
    +-- decode / PLDs        ($7Fxx selects, cart OE, etc.)
    +-- system RAM           ($0000-$7EFF)
    +-- cart flash PRG       ($8000-$FFFF)
    +-- VRAM mux             (CPU phase only)
    +-- MCU-M                (soft ports, may pull RDY)
```

## Sim notes

- Phase 1 accuracy: reset + vector fetch + correct read/write cycle shape + documented cycle counts per opcode over time.
- Clock the model from **PHI2 only**.
- Stack always `$0100-$01FF`.
- Match pin **names** above in the chip registry so islands can wire `"PHI2"`, `"RWB"`, `"A0"`, ...
