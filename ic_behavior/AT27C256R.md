# AT27C256R behavior

Microchip **AT27C256R** OTP EPROM. Retr01 **Color PROM** (qty **1**).

**Package:** 28-pin **PDIP** (600 mil). **Organization:** **32K x 8**. Retr01 uses **64** entries (6-bit index). Prefer **AT27C256R-45** (45 ns `tACC`).

**Board:** `../general_docs/hardware.md`. **Video:** `../general_docs/video-graphics.md`. Programmed **off the console** (no HV path on the motherboard).

---

## 1. Inputs (what pins can sense)

| Pin | Dir | What the net must provide |
| --- | --- | --- |
| **A0-A14** | IN | Byte address. Video path drives **A5-A0** with the 6-bit color index. **Tie unused address pins to GND** |
| **CE#** / **OE#** | IN | Active-low enables from the video / compositor path |
| **VCC** / **GND** | PWR | 5 V / GND |

During play this chip is **read-only** on the **video path**. It is **not** on the W65C02S data bus.

### Stimulus checklist

| Stimulus | Expect |
| --- | --- |
| CE#=L, OE#=L, A[5:0]=N (unused A high bits GND) | DQ = PROM[N] packed R3G3B2 after `tACC` |
| CE# or OE# high | DQ Hi-Z |
| Index change each dot | New DAC code within 45 ns grade + compositor pipeline |

---

## 2. Process (what happens inside)

One-time programmable parallel ROM. Factory or DIY burner blows the **64-color** master table. Wrong blow means a new chip (OTP).

### Retr01 role

| Topic | Spec |
| --- | --- |
| Master palette | **64** colors (indices 0-63) |
| Data format | Packed **R3G3B2** `{RRRGGGBB}` |
| Cart | Palette **indices only** in `.retr01` |
| Active game pals | `$7F08` PAL_ROW + `$7F09` PAL_DATA stream indices. Compositor resolves to PROM address |
| Analog | PROM DQ -> binary-weighted resistors -> **75 ohm** to GND -> **~0.7 Vpp** RGB |

### Speed vs dot clock

| Item | Value |
| --- | --- |
| Dot period | ~**186 ns** @ 5.369318 MHz |
| `tACC` (45 ns grade) | **45 ns** |
| Pipeline | Compositor may still use a 1-dot index latch. PROM is not the bottleneck |

### Programming

Parallel OTP programmer with the required VPP/VCC algorithm (~12.5 V class per datasheet). **Not** field-rewritable on the game board. Adafruit's UPDI Friend cannot program this part.

---

## 3. Outputs (what pins can drive)

| Pin | Dir | What the chip drives |
| --- | --- | --- |
| **O0-O7** (DQ) | OUT (Z if disabled) | Packed color byte `{RRRGGGBB}` into the resistor DAC |

### 28-pin PDIP (JEDEC 27C256-style)

```text
         +-----\/-----+
    VPP  | 1       28 | VCC
    A12  | 2       27 | /PGM (or NC on some markings)
     A7  | 3       26 | A13
     A6  | 4       25 | A8
     A5  | 5       24 | A9
     A4  | 6       23 | A11
     A3  | 7       22 | OE#
     A2  | 8       21 | A10
     A1  | 9       20 | CE#
     A0  |10       19 | O7
    O0   |11       18 | O6
    O1   |12       17 | O5
    O2   |13       16 | O4
   GND   |14       15 | O3
         +------------+
```

Confirm A14 / VPP / PGM against the frozen AT27C256R datasheet revision. After programming, treat VPP/PGM per datasheet read-mode ties.

| Num | Name | Dir |
| --- | --- | --- |
| 1 | VPP | IN (program) / tie in read |
| 2 | A12 | IN |
| 3-10 | A7-A0 | IN |
| 11-13 | O0-O2 | OUT |
| 14 | GND | PWR |
| 15-19 | O3-O7 | OUT |
| 20 | CE# | IN |
| 21 | A10 | IN |
| 22 | OE# | IN |
| 23-26 | A11, A9, A8, A13 | IN |
| 27 | /PGM or NC | IN / NC |
| 28 | VCC | PWR |

A14 exists on denser siblings. On 27C256-class parts the upper address story is datasheet-specific. Retr01 only needs **A5-A0** live for 64 colors.

### Where outputs go

```text
Compositor 6-bit index --> A[5:0] (+ CE/OE)
        |
   AT27C256R
        |
   R/G/B resistor DAC --> J2 RGB  and  AD724 RIN/GIN/BIN
```

## Sim notes

- Model as a **64-entry** read-only table (ignore unused array space unless testing address ties).
- Pin names: `"A0"`, `"OE#"`, `"O0"`, ...
- No CPU D-bus connection during play.
